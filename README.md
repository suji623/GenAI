# FitBuddy – AI Fitness Plan Generator

This folder contains the FitBuddy project documentation converted from the original 23-page project document into 8 organized PDF files.

## PDF structure

1. **01_Project_Overview.pdf** – Project description, scenarios, and core purpose.
2. **02_Prerequisites_and_Workflow.pdf** – Prerequisites and milestone/project workflow.
3. **03_AI_Model_Selection_and_Architecture.pdf** – Gemini model selection, architecture, frontend/backend/AI/database responsibilities.
4. **04_Environment_and_Core_Functionality.pdf** – Development environment and core AI/database functionality.
5. **05_Backend_Routes_and_API.pdf** – FastAPI routes, user input processing, Gemini integration, and route logic.
6. **06_Frontend_and_Jinja2.pdf** – UI design, HTML/CSS, Jinja2 templates, and dynamic rendering.
7. **07_Deployment_and_Testing.pdf** – Local deployment, environment variables, server startup, and testing.
8. **08_UI_Pages_and_Conclusion.pdf** – Application pages, generated plan/nutrition/feedback features, admin view, and conclusion.

## Technology stack documented

- Python
- FastAPI
- Google Gemini models
- Jinja2
- HTML/CSS
- SQLAlchemy
- SQLite
- Uvicorn
- Git/GitHub

## GitHub upload

Upload this folder to the repository as a documentation folder, for example:

`docs/FitBuddy_PDFs/`

Do not upload API keys or `.env` files containing secrets.
